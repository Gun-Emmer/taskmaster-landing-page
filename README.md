# TaskMaster - SaaS Landing Page

A modern, clean, and responsive product landing page for a task management application (SaaS). 

## 🌐 Live Demo
👉 **[Click Here to View Live Demo](https://username-kamu.github.io/taskmaster-landing-page/)** *(Ubah link ini dengan link milikmu)*

## ✨ Features
- 📱 **Fully Responsive Layout:** Optimized for Mobile, Tablet, and Desktop screens.
- 🍔 **Interactive Mobile Menu:** Dynamic hamburger menu powered by Vanilla JavaScript.
- 🎨 **Modern Design:** Built with Tailwind CSS utilities for styled UI components.
- 🏷️ **Pricing Section:** Clear subscription plans with highlighted popular choices.
- 🚀 **Smooth Scrolling:** Enhanced navigation experience across page sections.

## 🛠️ Tech Stack
- **HTML5** (Semantic Structure)
- **Tailwind CSS** (Styling & Responsive Layouts)
- **JavaScript (ES6+)** (DOM Manipulation)
